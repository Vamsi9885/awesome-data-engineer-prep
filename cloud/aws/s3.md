# Amazon S3 for Data Engineers

## 1) What is the Service?
Amazon S3 is AWS’s durable, scalable object storage and the foundation of most AWS data lakes.

## 2) When to Use?
- Raw and curated data lake layers
- Log/event archival
- Landing zone for batch and streaming outputs

## 3) Architecture Usage
`Kinesis/Lambda/Glue/EMR → S3 (raw/silver/gold) → Athena/Redshift Spectrum`

## 4) Real-World Example
Amazon-scale ecommerce:
- Orders, clickstream, catalog snapshots in partitioned S3 paths
- Athena for ad hoc, EMR/Glue for transforms, Redshift for BI

## 5) Integration with Other Services
- Glue Catalog
- EMR Spark
- Athena
- Redshift Spectrum
- Lambda triggers
- Lake Formation governance

## 6) Common Mistakes
- No partitioning
- Too many small files
- Weak lifecycle/retention strategy
- SELECT * scans from Athena

## 7) Performance Tips
- Parquet/ORC over CSV/JSON
- Partition by date + high-value filter dims
- Compact files to optimal sizes
- Use S3 Intelligent-Tiering and lifecycle rules
