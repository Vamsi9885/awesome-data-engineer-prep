# 📚 Essential Data Engineering Books

## Foundational (Must Read)

### 1. **Designing Data-Intensive Applications** (Martin Kleppmann)
```
★★★★★ Bible of distributed systems
Chapters 5-9: Replication, Partitioning, Transactions
Interview Gold: CAP Theorem, Exactly-once
```

### 2. **The Data Warehouse Toolkit** (Ralph Kimball)
```
★★★★★ Star Schema bible
Chapter 4: Retail sales example
Interview: Fact/dimension design
```

### 3. **Spark: The Definitive Guide** (Bill Chambers, Matei Zaharia)
```
★★★★☆ Production Spark
Chapter 12: Structured Streaming
Chapter 15: Performance Tuning
```

## SQL Mastery

### 4. **SQL Performance Explained** (Markus Winand)
```
★★★★★ Index deep dive
USE THE INDEX! (Luke)
Interview: Composite indexes
```

### 5. **Window Functions in SQL** (Alex Thomas)
```
★★★★☆ Window function patterns
Interview 90% hit rate
```

## Streaming + Modern

### 6. **Kafka: The Definitive Guide** (Neha Narkhede)
```
★★★★★ Kafka internals
Chapter 4: Producers, Chapter 5: Consumers
```

### 7. **Streaming Systems** (Tyler Akidau)
```
★★★★☆ Flink, Beam theory
Interview: Watermarks, late data
```

## Cloud Specific

### 8. **Cloud Native Data Lakehouse** (Matt Housley)
```
★★★★ Iceberg, Delta Lake
Interview: Table formats
```

## Interview Prep

### 9. **Ace the Data Science Interview** (Kevin Huo, Nick Singh)
```
★★★★★ LeetCode for DE
100 SQL + Python problems
```

## Advanced/Optional
